# Warehouse Datasets

The experiments can be run using either the original 3-tier warehouse
datasets or a smaller stratified sample.

### Option 1: Main 3-Tier Warehouse Datasets

The main 3-tier warehouse datasets are available on Hugging Face:
[Warehouse Inventory Management — Main Datasets](https://huggingface.co/datasets/electricsheepafrica/warehouse-inventory-management/tree/main/data)

Download the required files and place them in this `data/` directory.
Then, from the main project directory, run:

```
!python run.py --data-dir data --base-model Qwen/Qwen2.5-0.5B-Instruct --min-prompts 150 --out out --max-new-tokens 100
```

### Option 2: 210-Row Stratified Sample

For a smaller dataset suitable for quickly testing the pipeline or
reproducing a similar experiment to the one presented in this
repository, you can use the 210-row stratified sample generated from
the main datasets:
[Warehouse Inventory (by the author) — Stratified Sample](https://huggingface.co/datasets/EnRaoufi/warehouse-inventory-stratified-sample)

Download the sample file and place it in this `data/` directory,
named exactly `warehouse_sample.jsonl` - the pipeline looks for this
specific filename. Then, run:

```
!python run.py --sample --data-dir data --base-model Qwen/Qwen2.5-0.5B-Instruct --min-prompts 150 --out out --max-new-tokens 100
```

### Option 3: DPO Preference Pairs

The DPO preference pairs used for the experiments in this repository
are also available for direct download from Hugging Face:
[Warehouse Inventory (by the author) — DPO preference pairs](https://huggingface.co/datasets/EnRaoufi/warehouse-dpo-preference-pairs)

These preference pairs were generated by the author and correspond
directly to the data used for the experiments presented in this
repository. The dataset also includes `records.jsonl`, the normalized
warehouse records the pairs were generated from - `eval_model.py`
needs this to validate categories, reason codes, and tier/region
labels, and to score tool-selection accuracy.

Download `dpo_pairs.jsonl`, `eval_pairs.jsonl`, and `records.jsonl`,
and place all three in the `out/` directory. Then, from the main
project directory, run:

```
python train.py out/dpo_pairs.jsonl out/model Qwen/Qwen2.5-0.5B-Instruct
python eval_model.py out/model Qwen/Qwen2.5-0.5B-Instruct out/eval_pairs.jsonl out/eval_report.json out/records.jsonl
```

### Recommendation

- Use the **main 3-tier datasets** for the full-scale experiments.
- Use the **210-row stratified sample** for quickly testing or
  reproducing a similar experiment to the one presented in this
  repository.
- Use the **pre-generated DPO preference pairs** to precisely
  reproduce the experiment presented in this repository, as they are
  the exact preference-pair data used in the experiments.
